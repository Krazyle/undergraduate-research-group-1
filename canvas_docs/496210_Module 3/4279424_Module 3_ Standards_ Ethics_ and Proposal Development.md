## 📝 Module Description

Great research requires rigorous compliance and absolute academic integrity. This module focuses on the ethical dimensions of computing research, detailing data privacy laws, informed user consent, intellectual property rights, and algorithmic bias. You will learn to run proactive plagiarism detection checks and align your proposal document with modern computing and software engineering standards.

To prepare your manuscript for the final defense, you will participate in an anonymized, double-blind mock peer review cycle and transition your writing into a professionally typeset package using LaTeX and Overleaf publisher templates.

## 🎯 Module Intended Learning Outcomes (MILOs)

By the end of this module, you should be able to:

* 
Apply ethical principles and responsible research practices (e.g., consent, data privacy, citation ethics) in their proposal development.

* 
Align their proposal with relevant quality and technical standards (e.g., software engineering/documentation standards, reproducibility concerns).

* 
Revise drafts based on feedback (self, peer, instructor) and perform iterative refinement.

* 
Ensure proper attribution, avoid misconduct (e.g., plagiarism), and document compliance with ethical guidelines.
